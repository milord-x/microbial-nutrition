# Микроорганизмдердің қоректенуі

Пайдаланушының дайын PDF презентациясының 10 беті өзгеріссіз сайтта көрсетіледі. Беттер Poppler арқылы 1920 × 1080 PNG кескіндеріне айналдырылған. Мәтін, суреттер, беттердің реті және безендірілуі сақталған. PDF ішіндегі сілтемелер басылады, мәтін экран оқу құралдарына қолжетімді.

Жергілікті іске қосу: `python -m http.server 4187`.
Тексеру: `node check.mjs`.

Навигация: айналдыру, бағыттау пернелері, Page Up/Page Down, Home/End. Телефонда жоғары қарай сырғыту; ұсақ мәтінді браузердің стандартты масштабтауымен үлкейтуге болады. Бет индикаторлары жоқ.

Бастапқы PDF және оның SHA-256 мәні `slides/manifest.json` ішінде көрсетілген. PDF өзгертілмеген. Бөлек 3D галерея `/3d/` мекенжайында сақталған.
