# Микроорганизмдердің қоректенуі

Қазақ тіліндегі тоғыз бөлімді анимациялық веб-презентация.

Жергілікті іске қосу: `python -m http.server 4187`

Тексеру: `node check.mjs`

Навигация: айналдыру, ↑/↓, Page Up/Page Down, Home/End. Анимацияны тоқтату және толық экран батырмалары бар. Reduced motion жүйелік баптауы ескеріледі.

Мазмұнның дереккөздері сайтта берілген. ЖИ жіктеуі — алдын ала тексерілген мысалдар; сыртқы AI API қолданылмайды. Иллюстрациялар сызбалық, микрофотография емес.
