# Бактериялар 3D

Таза ақ фонда үш интерактивті сызбалық модель. Көлденең сүйреу модельді айналдырады. Пернетақта: Tab арқылы модельді таңдау, бағыттау пернелерімен айналдыру, Space арқылы қозғалысты тоқтату. Телефонда тік айналдыру келесі модельге өткізеді.

Модельдер микрофотография немесе молекулалық дәл реконструкция емес. Түстер шартты, өлшемдері өзара масштабталмаған. Жасушалық құрылымдар көрінуі үшін қабық мөлдір көрсетілген.

Anabaena: фотоавтотрофты цианобактерияның жасушалық тізбегі.
Nitrosomonas: аммиак тотықтыратын хемолитоавтотрофты бактерия.
Escherichia coli: хемоорганогетеротрофты, талшықтары бар бактерияның өкілі.
